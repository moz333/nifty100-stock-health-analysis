# Nifty 100 Stock Health Analysis

## Overview
Built an end-to-end analytics platform for Nifty 100 companies that:
- Extracts and cleans financial statement data
- Calculates key financial ratios
- Generates company health scores
- Stores data in PostgreSQL
- Visualizes insights in Power BI
